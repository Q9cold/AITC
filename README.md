# AITC
This system employs four ESP32-S3 chips to construct a collaborative computing architecture, forming a sensing-decision-feedback closed-loop where vision, pressure, voice, and interaction terminals operate in coordination. The vision module captures real-time facial images via a camera and utilizes a lightweight deep learning model to extract and model the spatial coordinates of five key landmarks: the left eye, right eye, left mouth corner, right mouth corner, and nose tip. By normalizing data based on interpupillary distance, the system resolves issues caused by variable camera placement, thereby achieving precise estimation of head pose and viewing distance. The pressure module integrates a 16×16 array of thin-film sensors capable of collecting real-time sitting pressure distribution data. The system features a specialized multimodal fusion board that receives visual coordinates via Bluetooth and pressure matrix data via a serial interface. It runs an offline-trained multimodal fusion scoring model to output nine-dimensional assessment results, including the degree of forward lean, backward lean, lateral tilt, head rotation, pressure balance, pressure centering, pressure uniformity, postural stability, and a comprehensive health score.
