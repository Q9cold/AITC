# AITC
本系统采用四片ESP32-S3芯片构建协同计算架构，形成了视觉、压力、语音与交互终端分工协作的感知—决策—反馈闭环。视觉模块通过摄像头实时捕获人脸图像，基于轻量化深度学习模型完成左眼、右眼、左嘴角、右嘴角及鼻尖五个关键点的空间坐标提取与建模，并通过瞳距标准化数据解决摄像头放置不定问题，从而实现头部姿态与视距的精确估计。压力模块集成16×16阵列式薄膜传感器，能够实时采集坐姿压力分布数据。系统专门设计了多模态融合板，通过蓝牙接收视觉坐标，同时通过串口接收压力矩阵数据，并运行离线训练的多模态融合打分模型，最终输出包含前倾程度、后仰程度、侧倾程度、头部扭转、压力平衡、压力居中、压力均匀度、姿态稳定性及综合健康评分在内的九维评估结果。
